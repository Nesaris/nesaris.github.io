Nesaris Network

Map, monitor and run your own network — on hardware you own.

Nesaris Network is a family of open-source services for your LAN and homelab: network mapping, fleet management, a Proxmox dashboard, security audit, reverse proxy, alert inbox and AI memory. They share one hardened core and install from the Hub in one click.

$ git clone https://github.com/Nesaris/Hub hub && cd hub && sudo ./install.sh

01 / Hub

Hub

The control point for everything you self-host.

Dockerworkflowsone-click installs
  • Installs services straight from GitHub, as extensions.
  • Real workflows between services: triggers, actions and probes.
  • Measured overview: traffic, CPU, memory and uptime over 24 h, 7 d or 30 d.
  • Docker driven through a socket proxy, never the raw socket.

02 / MapMyLAN

MapMyLAN

See every device on your LAN — and block the bad ones on your own router.

network mapCVEUniFi · OpenWrt · MikroTik · pfSense
  • Discovery from ARP, ping and your router, with a confidence score per device.
  • Measured topology: switch port and access point of each client.

02 — Shared core

Every service ships the same foundations.

Zero npm dependencies
Node.js 24 and its standard library only. Nothing to audit in a node_modules folder, nothing to break on the next update.
SQLite, built in
Data lives in node:sqlite. One volume to back up.
Accounts done properly
Argon2id passwords, passkeys, TOTP, recovery codes and a security log in every service.
Secrets sealed outside the data
A master key mounted as a Docker secret: a copy of the data volume alone opens nothing. Key rotation is built in.
No build step
Static interfaces, light and dark, responsive from 360 to 1920 px.
Wired together by the Hub
Install any service from the Hub catalog and it gets its accounts, tokens and HTTPS route automatically.
